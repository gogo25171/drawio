## Description

Les plugins sont des modules complémentaires qui étendent les fonctionnalités de Draw.io. Ce document décrit le plugin de génération de code UML.

## Création de plugins et installation

Pour ajouter un plugin, placez-le dans le répertoire `plugins/` et ajoutez-le à la liste des plugins dans `js/diagramly/App.js`.
